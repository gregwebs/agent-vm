# Files the host Python guard (no-host-python.sh) accepts. ADR-0072 requires
# that building and testing the repository needs no `python3` on the host.
#
# Format: a `*.py` file is a bare path; a `*.sh` or `*.rs` file carries the number
# of Python occurrences it excuses. A count that is too low means a new call got
# in, and one that is too high means a port left it behind. Both fail, so this is
# a ledger of debt with a running total, not a per-file veto.
#
# Three kinds of entry:
#
#   Guest exceptions - Python that runs inside the guest, not on the host.
#   Permanent, unless the guest image drops Python.
#
#   Vendor tooling - upstream's own Python, which this repository does not own.
#   Out of scope, like the libkrunfw build's pyelftools.
#
#   Migration debt - Python still on the host. Each port ticket lowers or deletes
#   its own numbers.
