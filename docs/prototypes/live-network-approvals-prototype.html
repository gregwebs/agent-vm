Live network approvals: experience sketches

PROTOTYPE for Choose the notification and approval experience. All four variants share the same rules. A denied request has already failed. Approval happens only on the host, by an explicit human choice of this session or always for this project, and the app or user retries afterwards. Use ← → (or the bar) to switch variants and the tabs to switch scenarios. Command names are placeholders.

approvable a network allowance would permit it · locked an administrator/platform restriction; no prompt can lift it · not network a credential or GitHub repository refusal, which is a different authority and never shown as approvable here
